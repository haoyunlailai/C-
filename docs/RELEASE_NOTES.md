# C盘清理助手

一款面向 Windows 的本地磁盘空间分析与清理工具。六大模块覆盖临时文件、重复文件、应用缓存、软件卸载和磁盘空间可视化，全程离线运行，不上传任何数据，删除前必须由用户确认。

## 本次更新（v1.0.1）

- 修复从 `DisplayIcon` / `UninstallString` 反推安装目录时，带引号的命令、静默参数和 MSI 安装包解析失败的问题
- 补充对 AMD 等发布者的识别，减少系统组件误判
- 新增 126 个 pytest 单元测试，覆盖树状图布局、路径推断、安全规则、重复文件检测等核心逻辑
- Release 附件改由 GitHub Actions 自动构建：推送 `v*` 标签即可完成测试、打包与发布

## 功能一览

| 模块 | 能力 |
| --- | --- |
| 临时文件清理 | 分类概览，按文件类型给出三级清理建议，危险项默认隐藏 |
| 磁盘扫描 | 全盘或指定目录扫描，阈值可调，实时进度 |
| 重复文件 | 大小分组 + MD5 两阶段检测，同组保留一份，批量移入回收站 |
| 应用缓存 | 自动识别微信、QQ、钉钉、QQ 浏览器，清理后自动复扫 |
| 软件卸载 | 注册表枚举，识别超过半年未使用的软件，调用原生卸载程序 |
| 磁盘可视化 | Squarified Treemap 逐层下钻，父节点缓存复用 |

## 下载与运行

- 下载 `C.exe`，适用于 Windows 10 / 11（64 位）
- 双击直接运行，无需安装 Python
- 所有扫描与删除均在本机完成；敏感文件与受保护的系统目录默认排除
